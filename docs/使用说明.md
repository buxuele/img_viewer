# 使用说明

## 打开图片

1. 启动后点左上角打开文件夹，或在输入框里粘贴文件夹完整路径后回车。
2. 在缩略图网格里点一张图片进入查看器，超过 30 张时用底部页码翻页。
3. 查看器左上角的关闭按钮或 Esc 返回图片库。

## 鼠标

1. 滚轮：以光标所在位置为中心缩放。
2. 双击图片：在适应窗口与 100% 之间切换。
3. 放大后按住左键拖动：平移画面。
4. 右键：打开菜单，包含复制、复制路径、在访达中显示、另存为、设为桌面背景、旋转、删除、属性、选项。

## 键盘

1. 左右方向键、PageUp、PageDown：上一张、下一张。
2. Home、End：第一张、最后一张。
3. 加号、减号：放大、缩小。
4. Ctrl+0：适应窗口。
5. Ctrl+1：实际大小。
6. Ctrl+. 或 Ctrl+R：顺时针旋转。
7. Ctrl+, 或 Ctrl+L：逆时针旋转。
8. Delete：删除当前图片，先弹出确认。
9. F11：进入幻灯片，空格暂停，Esc 退出。
10. Alt：临时显示文件菜单，再按一次或 Esc 收起。

## 选项

1. 常规：打开时适应窗口、始终显示菜单、记住最近文件夹、滚轮缩放、双击切换、图片区背景。
2. 幻灯片：每张停留秒数、循环播放、随机顺序、黑色或白色或渐变主题。

## 启动

./just_run.sh

脚本会检查虚拟环境与依赖、探测 8770 端口，服务就绪后自动打开浏览器。重复运行只会打开已运行的页面，不会重复起服务。
