# 使用说明

## 打开图片

1. 启动后点打开文件夹，或在最近打开列表里选一个文件夹。
2. 打开后显示文件夹里第一张图片，左右箭头或方向键切换。
3. 文件菜单里可以打开单张图片，也可以从访达里把图片拖到应用图标上打开。

## 鼠标

1. 滚轮：以光标所在位置为中心缩放。
2. 双击图片：在适应窗口与 100% 之间切换。
3. 触控板双指捏合：连续缩放。
4. 放大后按住左键拖动：平移画面。
5. 右键：复制图片、复制路径、在访达中显示、另存为、设为桌面背景、旋转、删除、属性、选项。

## 键盘

1. 左右方向键、PageUp、PageDown：上一张、下一张。
2. Home、End：第一张、最后一张。
3. 加号、减号：放大、缩小。
4. Command+0：适应窗口。
5. Command+1：实际大小。
6. Command+R：顺时针旋转。
7. Command+L：逆时针旋转。
8. Delete：删除当前图片，先弹确认。
9. F11：进入幻灯片，空格暂停，Esc 退出。
10. Command+,：打开选项。

## 选项

1. 常规：打开时适应窗口、记住最近文件夹、滚轮缩放、双击切换、图片区背景。
2. 幻灯片：每张停留秒数、循环播放、随机顺序、黑色或白色或渐变主题。

## 启动

./just_run.sh

脚本会生成 Xcode 工程、增量构建 Release 应用并在前台启动，终端保持占用直到应用退出。重复执行只会激活已经在运行的实例。
